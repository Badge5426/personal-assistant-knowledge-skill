# 来源路由与源章节反向覆盖

用于首次建库、对照修复或内容否决后的复验。保留七类/13页与唯一可写主来源。字段都有不证明资料完整。

## 来源路由

从真实URL/元数据识别对象，再发现当前工具schema，核实际返回身份与精确目标。工具名字有search/thread不证明它能读该来源。

| 定位 | 当前入口及核验 |
| --- | --- |
| Page/Space | Page工具；Space先取root_page_id；读完整正文、指导、来源及版本 |
| chatgpt.com/c/对话ID与messageId | 实际可用ChatGPT对话阅读器或Global Search的read_conversation_context；精确conversation_id/message_id核返回作者、正文和ID，不用公开web搜索读私人聊天 |
| Codex任务与host | native read_thread；用真实kind/host/thread.id/cursor，近期文字不代替指定旧消息 |
| Library文档 | 当前Library read/find或其支持的本地材料化；保留文件标识、版本、行/页与图像读取边界 |
| 明确项目文件 | 在本次允许范围读明确档案与使用说明；项目路径不授权全盘遍历 |
| memory指针 | 当前允许位置定向读摘要，原话按其真实来源路由；摘要不升级直接证据 |

若native接口确实返回ChatGPT内容，可使用；reader_kind根据实际返回来源，不按工具名称判断。核目标消息是否返回。旧错误入口、旧环境缺工具或目标未返回不能永久继承为不可读：在原授权内检查本次正确入口，没入口准确报告本执行环境未覆盖。当前明确拒绝停止该源，不换路径绕过或新增权限/凭据/连接。旧拒绝保留其当时范围，不自动授权重试。

指定消息完整只证明该窗口，不证明整段对话。逐目标核正文遗漏/截断；只返回ID不证明正文完整。content_omitted/truncated未报告不是false；逐目标缺某旗标时，只有对应聚合旗标明确false才可证明该维完整，否则保留unknown。目标自身明确true为incomplete，逐维明确false才可确认指定窗口完整。响应遗漏而无法确认是否涉及目标时保留partial，不能假定遗漏都在其他消息。保留content_omitted、前后游标、截断、附件/图像未读；必要目标没返回先定向续读。整个来源完成需核双向已读范围与正文遗漏，末页不能代替前半。补读无新增正文且无另一获准正确入口时停止本轮，保留已返回事实和不可得限制，不循环重试。检索时间不成为事件/确认日期。

## 从章节核实际正文

先列获准来源的相关章节/块，再选需要保留的事实；不能由旧固定字段表倒推只找支持句。每个章节标保留事实、摘要＋定位、仅链接、隐私/无关排除，或未读/待核，并说明理由。未读不可伪排除。每项映射至现有七类，独立项目在同页分组，不增加空页或启动旧项目。

保留影响判断的**实体、动作、时间、状态、边界**：设备型号/关系对象/渠道的历史已知不因当前可用性未知被抹去；接触、独立完成、AI或专业协作、交付、验收、盈利分别记。搭建过、未持续、已失效不都缩成“会工具”。已选先A、B后置与平台实现待定分开。使用偏好、整理分工、保存倾向、家庭约束和非固定时间窗口不被未知工时/预算吞掉。已发内容类别和实时效果分别记。

源→正文找遗漏章节与细节；正文→源查状态升级、顺序改变、项目混淆、日期补造与边界丢失。目标取舍、允许失败返工、已撤回旧误判也要评估承接；历史情境排序保留定位，不合成永久评分/人格或恢复旧产能承诺。只留必要主题入口与历史状态即可承接金融/法律/健康/儿童资料，不批量搬金额、持仓、诊疗、争议全文或客户住址。不因读到这些而给新专业建议或恢复提醒。

源章节包含的独立相关链接要读取或明确未读，不能用已读父索引冒充。记录所用源版本，写前/审核时重读动态源；只比较并刷新变化章节，不锁死旧版本，不把整页更新日当所有事实重新确认。主条目与工作台/覆盖记录的投影同时核对。

## 可选纯离线辅助

`scripts/content_review.py`只检查Agent标注与提供的实际读回正文，不读账户、自动抽取语义或写Page。输入放公开仓库外私人目录，输出stdout：

```sh
python3 -B skills/maintain-personal-context/scripts/content_review.py --input "$PRIVATE_COVERAGE_INPUT"
```

`sections`各项有唯一`id`、真实`source_id`、实际`scope/status`（read/partial/discovered_unread/inaccessible/stale），非read附`reason`。有观察版本时成对填`read_version/latest_version`；变化则待刷新。已读不导入附`excluded_reason`，否则列`atoms`：唯一`id`、七类现有`role`（identity/experience/resources/goals/projects/results/sources）、来源先确定的关键短语`required_terms`。不从生成结果倒推降低标准。

`projections`各项有实际`page_ref/role/text/readback`及引用`atom_ids/source_ids`；text取实际读回，不把拟写草稿标已保存。默认`kind=body`逐个核角色、出处、读回及必要短语；一个正确主条目不能遮住同atom的错误投影，每个错误目标分别列issue。

稳定档案等只有主条目引用的投影可显式填`kind=reference`，不要求复制所有事实。其`references`按atom_id列`target_ref`及实际Markdown链接`literal`；literal必须链接到该target_ref且出现在读回正文中，target_ref使用对应主条目body的实际page_ref。被引用主条目须针对同atom已读回、角色/出处匹配且保留必要短语；引用链不能代替主条目正文，不存在/错误目标或未读回引用仍报缺口。仅引用时投影自己的role可为链接所在类别、source_ids可空，事实出处由实际主条目核验；它不成为另一份可写事实。短语检查可辅助发现实体和状态丢失；同义改写由独立审核核义后调整标注，不能让字面命中代替判断。

`annotations_matched`仅表示所列标注匹配；`coverage_limits/read_scope_complete`另报，均不是内容PASS。遗漏未列章节、语义正确性、排除理由、真实权限、用户认可和账户全量仍需独立判断。

## 固定远端重新运行

安装、加载、运行、内容覆盖、独立审核、用户认可分开。审核通过后固定远端commit，在新的隔离项目下载并核所有安装SHA，显式读安装后的Skill/规则，记录路径与提交；不加载开发目录、旧状态或后补页面。保留现有验收和原文件，正式来源只读，新目标先验证实际私有性，不改分享。

用户要求独立运行时，新执行模型只接收授权、正式入口、可选定位与隔离验收目标；不预填调试差异、旧正文或标准答案。按安装Skill自主发现、读取/分页、提炼、写回/读回，生成后再用私人差异独立比对。缺独立上下文能力如实报告，不能把同模型答案回放称独立。匿名不同背景验证另报，不证明真实账号覆盖。手工补旧库或离线测试不能代替干净远端运行。
