# Space 作为可选输出层

Space 必须已在用户账号开通，并由本次会话可用工具读到目标与权限。仅安装 Skill 不会开通 Space 或连接外部资料。

1. 复用用户指定的目标页/容器、主来源和现有页面映射。只读本次相关内容；私人 Page ID、访问令牌、真实路径不得写进公开源码或示例。
2. 找到已有映射先读取原页；没有指定目标页/容器且无映射时，先请求明确目标，不为定位目标遍历全部 Space 或页面。获准容器已明确时可按名称检索，存在多个候选就先给差异。不能遇到错误便重新创建一份页面。
3. 读到完整相关页面和当前版本后才生成具体变更。工具支持版本/更新前置条件则使用。没有前置条件时重读确认版本未变，但如实说明仍存在并发风险。
4. 保留用户内容；另一维护任务拥有的页不写。只修改授权范围。读权限不等于写权限。
5. 一次创建调用只用于确定不存在且已授权的目标；未知结果先查证创建状态/目标，不能盲重试制造副本。
6. 写后重新读取核验正文与目标。没有成功读回就报告“写入尚未确认”，保留本地草稿，不声称同步完成。

无工具、未开通、缺权限、读取不完整：交付本地 Markdown，明确“未创建/更新 Space”。不给用户要求获取全部私数据或扩大所有账户权限。
外部文件需相应 app 连接和文件权限，允许用户只提供选择的文本作为替代。

单向导出：副本注明来源和导出时间，只读源、只写选定目标；目标已有改动先展示差异。禁止自动双向覆盖。
Page 中写更新频率不是创建定时任务；本 Skill 不创建计划、后台或 keep-updated 服务。

依据：
- [Space 起步与账号访问](https://learn.chatgpt.com/docs/space/getting-started)
- [Space 中的 Agent 与独立计划验证](https://learn.chatgpt.com/docs/space/agents)

本包没有 Space API 代码；本地自动测试只验证缺能力时的交付边界，不能证明真实账号写页成功。
