# 调用提示

首次建立：使用 $maintain-personal-context，在当前已连接账号建立我的私有个人助手 Space。整理我本次授权的 Codex 对话与项目，先说明实际工具范围，不读未授权文件、不改变分享；完成目录和有来源的内容后给真实入口、覆盖缺口和最多三项补充问题。

仅部分历史：续建原知识库，只整理我指定的这几个对话，不扩大到其他聊天或文件。复用私人映射，先读现有相关页，保留手改。

补充：把以下回答保存到上次建库的对应页，确认日期为这次回复日期；未知日期不猜。它只确认这些具体回答，不确认其他推断。

纠错：把经历技能中的该条更正为以下内容，保留旧来源与替代关系，生效日期按我给出的日期；未来生效先留计划。

导出：从已映射 Space 单向导出 Markdown 到指定仓库外目录，注明实际来源和导出时间；已有文件不要覆盖，先比较差异。保留 Space 为主源。

本地选择：这次明确使用本地 Markdown 主源，根据我指定的材料起草/写入。Space 没有权限时不要说已建页。
