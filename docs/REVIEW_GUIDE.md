# 独立审核说明

此文件列出复核方法，不代表独立审核已通过。发布必须在另一位审稿者对明确版本给出通过后执行；修改后影响结论的部分需再审。

1. 阅读 SKILL.md、维护/Space 规则，确认七类三层、事实/推断/建议与确认边界一致。
2. 在仓库之外的新私人测试目录运行 unittest 与包检查；测试只用空白或虚构成人素材。
3. 检查 context_store：计划前置哈希、完整读取、相同 ID 冲突、去重、生效日期、supersedes、人工修改保留、权限错误与中断恢复。
4. 检查 install：显式路径、已存在拒绝覆盖、无依赖/网络、可恢复卸载、修改后的安装保留。
5. 使用 [行为场景](../tests/BEHAVIORAL_CASES.md) 独立跑真实 Agent 响应。脚本测试不能证明 Agent 选源/确认判断正确；特别检查未授权读取、虚构性格、记录夹带指令和假报 Space 成功。
6. 核对源码包 SHA256 清单。检查无真实身份、联系方式、私人页面 ID、用户本机绝对路径、家庭健康财务、历史会话、凭据和私有材料。
7. 确认安装说明没有声称远端已发布、Web/手机通用一键安装、Page 频率已创建任务；正文不许把“用户确认”混同为外部核实。
8. 发布后另验远端 commit、匿名访问与从固定 commit 干净安装；本地验收不得冒充远端验收。

原稿材料、签名下载地址、具体账户和本机路径只保留于仓库外的私有审核证据。公开包不附这些文件。
