# 独立审核与八项验收

本文件列复核方法；当前验收范围与限制见 [测试报告](TEST_REPORT.md)。审核对象是本包匿名源码、清单/diff、可复现测试及公开包外的私人连接态证据。不能用旧版 46 测试、关闭 apps 的调用或 mock 替代 Space 连接态。

| 项 | 审核内容 | 已有证据 / 限制 |
| --- | --- | --- |
| 1 | 真 Space/root/七类/三层/工作台，映射和逐页读回 | 13 个角色真实创建读回，actual parent/Space 检查；原始回执私人保存 |
| 2 | Codex/ChatGPT/项目分开发现，分页/归档遵权限 | 原生列表/摘要/归档/项目实际探测；无全量/cloud 接口明确缺口 |
| 3 | 去重五种状态、数量/时间/继续位置，总量未知 | 私人来源账本与公开规则；账户元数据探测与三个人工夹具分开 |
| 4 | 事实/建议/第三方、来源日期、纠错、历史注入 | 匿名完整夹具，实际页纠错 8→3→4，手工语义核验；注入未执行 |
| 5 | 重复零创建、根/部分页/unknown/部分成功恢复 | 真 13 页第二次只读；checkpoint 续建；丢响应为 mock，完整性未知先停；实际部分 patch |
| 6 | 同名不认领、手改保留、版本冲突与读回 | helper 不变量 mock；N-3 模拟手改 + 真实 stale guard/部分结果 |
| 7 | 私有验证、公开包匿名、缺能力失败精确报告 | 各页真实完整分享证据；故障为 mock；新增 CLI 调用明确失败 |
| 8 | 真入口/目录/覆盖缺口/最多三项补问 | 私人验收根页有链接、覆盖和补充；不是用问卷代替检索 |

审核命令：

```sh
python3 -m unittest discover -s tests -v
python3 scripts/check_package.py
```

检查 source-only 清单没有 .git、缓存、raw audit、真实用户资料、账号 ID、Page/Library ID、绝对本机路径或凭据。LICENSE 为原创 MIT，不复制第三方实现。

需要独立审稿人自行判断 Agent 指令是否足够、安装后的触发是否能在实际客户端完成。正常 Work 中已显式读取安装 RC2.1 的 SKILL.md 及引用规则，用三个完整匿名来源验证空白首次建库、增量维护、受控续跑与重复调用；该范围已独立复核。新 CLI 模型调用被 sandbox/自动审批阻止，客户端自动发现、独立新模型、UI 渲染与真实账户历史逐会话整理仍未验收。不得把显式加载通过扩大为这些范围通过。

PASS 后更新现有公开仓库；不新建公开 repo，不发小红书，不公开真实 Space。发布后才更换安装 pin 并核对远端 commit、公开读、全部文件和干净安装。审核修改后重跑受影响项；不能把父任务一句“继续”当 PASS。
