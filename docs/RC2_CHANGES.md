# RC2 修订依据

RC1 未发布。独立审稿提出的问题已用虚构资料复现：

1. 连续纠错后，中间记录同时持有 supersedes 与 superseded 状态，旧验证规则拒绝了合法历史。现在新输入仍要求明确确认；合法历史替代保留原确认日期/依据。整体替代关系与最终 Markdown 在写前校验。
2. 根目录以上的符号链接可绕过词法路径检查。现在检查全部祖先，按规范路径判断公开包/已安装 Skill 内部的输出；安装目标和计划路径也检查。系统别名路径会拒绝，应使用选定目录的真实路径。
3. Markdown-only 迁移说明与 init 拒绝非空目录冲突。README 现在建议复制完整私人目录并核对；仅有 Markdown 时按普通文稿维护，当前没有单独导入恢复命令。

新增四项回归在 RC1 上得到三项失败、一项错误；修订后通过。具体红/绿输出在审核证据中，真实客户端/模型行为与确定性回归分别报告。

真实 Space 能力探测中，模型将泛称“我的 Space”理解为可定位容器，并创建了单独虚构测试页；该页已核验并移到回收站，未编辑原页。输出规则随后收紧：未指定目标页/容器且无映射时先明确目标，禁止为定位目标遍历全部 Space/页面。原模型行为不能作为这条修订的通过证据；另留修订后的无 apps 实际调用记录。连接状态下目标缺失的完整行为仍须独立审稿，不重复用真实账号做探测。
